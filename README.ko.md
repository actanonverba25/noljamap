# 서울 클럽맵 (Seoul Club Map)

전국(서울·부산·대구·수원) 클럽/베뉴를 **지역**으로 찾는 큐레이션 지도.
[거지맵](https://xn--v69ak0xskm.com/)/[야장맵](https://news.sbs.co.kr/news/endPage.do?news_id=N1008566014) 프레임(위치기반 + 테마 필터) +
손그림 홍대맵(@b_reak_down) 감성(컬러 라벨)을 합친 v1 프로토타입.
데이터는 인스타 큐레이션 계정(@holycow.co.kr·@beatbuddy.kr) 크롤 **100곳**(지역별 컬러).

## 빠른 실행

```bash
# 1) 카카오 JS 키 설정
cp config.example.js config.js
#    → config.js 안의 키를 본인 JavaScript 키로 교체
#    → developers.kakao.com 에서 플랫폼 Web 사이트 도메인에 실행 주소 등록

# 2) 로컬 서버 실행 (file:// 직접 열기는 fetch가 막혀서 안 됨)
python3 -m http.server 8000

# 3) 브라우저에서 http://localhost:8000 접속
```

## 구조

| 파일 | 역할 |
|---|---|
| `index.html` | 레이아웃 (탑바 · 필터 · 지도 · 상세카드 · 범례) |
| `app.js` | 카카오 SDK 로드, 좌표 해석, 필터, 마커/카드 렌더 |
| `styles.css` | 다크 테마 + 장르별 컬러 라벨 |
| `data/clubs.json` | 클럽 시드 데이터 (장르·난이도·주소·인스타) |
| `config.js` | 카카오 키 (gitignore, 직접 생성) |

## 좌표 해석 방식

좌표를 직접 박지 않고 **카카오 실데이터로 런타임 해석**한다:
- `address`가 있으면 → 주소 지오코딩
- 없으면 → 지역 중심 4km 반경으로 편향한 **장소검색** 첫 결과
- 둘 다 실패 → 지역 중심점 fallback

> ⚠️ 이름이 일반적인 클럽(예: 사운드·링·오션)은 장소검색이 엉뚱한 위치를 잡을 수 있음.
> 배포 전 `data/clubs.json`에 정확한 `address`를 채워 검증할 것.

## 데이터 상태

- 모든 항목 `verified: false` — 장르/난이도/가격은 웹 리서치 기반 1차 큐레이션
- **배포 전 실사 확인 필요**: 영업 여부, 정확 주소, 입장료, 인스타 계정
- 라이선스: 출처 표기 시 배포 가능 / 상업적 이용 불가
